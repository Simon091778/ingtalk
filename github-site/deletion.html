계정 및 데이터 삭제

잉톡 계정과 관련 데이터의 삭제를 요청하는 방법입니다.

앱에서 즉시 삭제하기

  1. 잉톡 앱을 실행합니다.
  2. 하단의 내 정보로 이동합니다.
  3. 회원 탈퇴를 선택합니다.
  4. 확인 문구를 입력하고 계정과 데이터 영구 삭제를 누릅니다.
회원 탈퇴는 되돌릴 수 없습니다.

탈퇴 후 프로필, 콘텐츠와 이용자에게 표시되던 대화는 복구되지 않습니다.

앱을 사용할 수 없는 경우

고객지원 이메일로 외부 삭제 요청을 접수할 수 있습니다. 타인에 의한 삭제를 방지하기 위해 앱 이용 정보 등을 통한 추가 확인을 요청할 수 있습니다.

채팅 내용, 비밀번호, 신분증 사진은 첨부하지 마세요.

탈퇴는 연결된 휴대폰·Google·카카오 로그인 수단과 모든 등록 기기가 공유하는 잉톡 계정 전체에 적용됩니다. 연결된 로그인 수단으로 삭제된 계정이나 포인트를 되살릴 수 없습니다. 외부 요청에서는 계정 소유 확인 후 처리하며 닉네임만으로 다른 사람의 계정을 삭제하지 않습니다.

계정과 함께 삭제되는 정보

  • 프로필, 프로필 사진과 위치
  • 대화 카드, 게시글, 댓글과 첨부 사진
  • 대화 신청, 이용자에게 표시되는 채팅방과 메시지
  • 포인트, 출석·활동 보상, 차단 정보와 푸시 토큰
