# 스토어 개인정보 표시 체크리스트

이 문서는 Play Console `데이터 보안` 및 App Store Connect `앱 개인정보` 답변을 실제 구현과 맞추기 위한 작업표입니다. 최종 답변은 SDK 대시보드와 서버 로그를 다시 확인한 뒤 제출합니다.

## 수집 가능성이 높은 데이터

- 사용자 ID: Supabase 익명 계정 UUID, 설치 식별자
- 개인 정보: 닉네임, 나이/출생연도, 성별, 관심사
- 위치: 앱 사용 중 위치(선택)
- 사진: 프로필 및 게시글 사진(선택)
- 사용자 콘텐츠: 대화 카드, 게시글, 댓글, 메시지, 신고 내용
- 앱 활동: 좋아요, 대화 신청·수락·차단, 포인트 거래
- 앱 정보 및 성능: 오류 로그, 앱 버전, OS 정보(Sentry)
- 기기 식별자: 푸시 토큰과 부정 가입 방지용 설치 식별자

## 제출 전 확인할 질문

- [ ] HTTPS/TLS로 전송 중 암호화됨
- [ ] 데이터 판매 없음
- [x] 광고 SDK 및 광고 식별자 권한 미포함 확인
- [x] ATT 및 연락처 권한 모듈 미포함 확인
- [ ] 정확한 위치인지 대략적 위치인지 스토어 답변과 일치
- [ ] Sentry의 개인정보 마스킹 및 보존기간 설정
- [ ] Supabase 프로젝트 리전과 국외 이전 항목 확정
- [ ] 앱 안 계정 삭제가 정상 작동
- [ ] 외부 계정 삭제 요청 URL을 공개 배포
- [ ] 개인정보처리방침을 앱 안과 스토어 양쪽에서 접근 가능하게 연결

## 현재 주의사항

현재 출시 설정에는 광고 ID, 광고 추적, 연락처, 카메라, 마이크 및 광범위한 저장소 권한이 포함되지 않습니다. Android는 인터넷과 사용 중 위치만 선언하며, 알림은 운영체제의 런타임 동의로 처리합니다. 사진은 사용자가 시스템 선택 화면에서 직접 고른 항목만 처리합니다.
