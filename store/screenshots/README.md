# 스토어 스크린샷 제작 계획

실제 기기 화면을 사용하며 데모 이용자 이름·사진은 촬영 동의를 받은 자료 또는 명백한 데모 자료만 사용합니다. 실제 전화번호, 위치, 사용자 ID와 개인 대화는 포함하지 않습니다.

## 권장 5장 구성

1. `01-discovery` — 발견 목록: “관심 있는 대화를 발견하세요”
2. `02-request` — 대화 신청: “수락 후 시작되는 안전한 대화”
3. `03-chat` — 1:1 대화: “프로필을 확인하며 이어가는 이야기”
4. `04-board` — 게시판: “글마다 바뀌는 익명 별칭”
5. `05-safety` — 신고·차단 또는 내 정보: “신고·차단·계정 삭제까지”

## 캡처 규격

- Apple 기본 세트: iPhone 6.9형 세로 `1290×2796` 또는 Apple이 허용하는 6.9형 규격 중 하나, 1~10장, PNG/JPEG, 알파 채널 금지
- Google Play: 세로 스크린샷 2장 이상 권장, 각 변 320~3840px 범위, 동일 방향 세트
- Google Play 아이콘: `512×512`, 32-bit PNG, 1MB 이하
- 원본 보관: 상태바를 포함한 실제 기기 캡처 원본과 최종 업로드 파일을 분리

## 촬영 절차

1. 데모 계정 2개와 심사용 안전한 대화·게시글을 준비합니다.
2. 위치는 정확한 주소가 드러나지 않도록 거리만 표시합니다.
3. 푸시 토큰, UUID, 관리자 화면은 캡처하지 않습니다.
4. iPhone과 Android에서 각 화면을 실제로 캡처합니다.
5. 원본을 `store/screenshots/raw/ios`와 `raw/android`에 넣습니다.
6. 문구 오버레이를 적용한 최종본을 `final/ios`와 `final/android`에 저장합니다.

> 현재 자동 캡처는 Expo 웹 실행의 네트워크 실패로 생성하지 않았습니다. 실제 기기 화면을 제공하면 규격별 최종본으로 가공할 수 있습니다.
