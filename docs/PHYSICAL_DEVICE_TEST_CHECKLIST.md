## 출시 차단 기준

- P0: 데이터 노출·삭제 실패·포인트 중복 지급·앱 실행 불가
- P1: 가입·발견·신청·채팅·게시판·알림 핵심 흐름 불가
- P0/P1이 하나라도 남으면 Preview 승인 불가

## A. 설치와 권한

- [ ] iOS 신규 설치에서 동의 버튼이 한 화면에 보인다
- [ ] Android 신규 설치에서 상태 표시줄 및 하단 시스템 메뉴와 겹치지 않는다
- [ ] 위치 거부 상태에서도 발견 카드가 보이고 거리는 `?`로 표시된다
- [ ] 위치·사진·카메라·알림 거부 후 내 정보의 권한 설정에서 재허용할 수 있다
- [ ] 앱을 백그라운드로 보낸 뒤 설정에서 권한을 바꾸면 복귀 시 상태가 갱신된다

## B. 프로필과 사진

- [ ] 양 플랫폼에서 프로필 사진 선택·변경이 완료된다
- [ ] Android 사진 선택 화면에서 잘못된 자르기 동작을 요구하지 않는다
- [ ] 발견·채팅에서 사진 확대, 핀치 줌, 닫기가 반복 동작한다
- [ ] 사진 업로드 중 네트워크 단절 시 오류가 보이고 앱이 멈추지 않는다

## C. 발견과 톡쓰기

- [ ] 기기 A의 톡이 기기 B에 최근순으로 나타난다
- [ ] 위치 없음/15km/30km/50km/전체 필터가 정확하다
- [ ] 한 사용자의 새 톡이 기존 톡을 대체한다
- [ ] 수정·삭제가 다른 기기에 실시간 반영된다
- [ ] 키보드가 열린 상태에서도 취소·등록 버튼을 누를 수 있다

## D. 익명게시판

- [ ] 글·사진·댓글·좋아요·조회수·삭제가 양 기기에 반영된다
- [ ] 게시글과 댓글 작성자의 익명 별칭 규칙이 유지된다
- [ ] 수락 전 받은/보낸 신청에는 실제 닉네임이 노출되지 않는다
- [ ] 수락 후 실제 닉네임과 게시판 익명 닉네임이 함께 표시된다

## E. 채팅과 동시성

- [ ] 신청 시 정확히 100P 차감되고 연속 탭으로 중복 차감되지 않는다
- [ ] 두 기기에서 동시에 수락해도 채팅방은 하나만 생성된다
- [ ] 채팅방을 열어 둔 상태에서 메시지가 즉시 추가된다
- [ ] 다른 탭·백그라운드·강제 종료 상태에서 배지와 푸시가 갱신된다
- [ ] 같은 상대에게 다시 신청하면 기존 방에 메시지만 추가된다
- [ ] 삭제 시 양쪽 목록에서 방이 사라지고 차단 시 재신청이 불가능하다
- [ ] 신고가 관리자 대시보드에 나타나고 제재·감사 기록이 남는다

## F. 포인트

- [ ] 최초 설치·최초 프로필에만 100P가 지급된다
- [ ] 같은 기기에서 탈퇴 후 재가입하면 0P이다
- [ ] 출석·톡·게시글·댓글 보상은 각각 24시간에 한 번만 지급된다
- [ ] 두 기기/연속 탭에서도 중복 보상이 발생하지 않는다
- [ ] 잔액 부족 시 신청과 거래 내역이 모두 생성되지 않는다

## G. 회원 탈퇴

- [ ] 확인 문구가 일치하지 않으면 삭제 버튼이 비활성화된다
- [ ] 탈퇴 후 Auth 사용자·프로필·콘텐츠·채팅·포인트가 삭제된다
- [ ] `avatars`, `board-images`의 사용자 폴더가 삭제된다
- [ ] 상대방 기기에서도 삭제된 채팅방이 사라진다
- [ ] 네트워크 단절 후 재시도하면 남은 데이터가 정리된다
- [ ] 완료 후 최초 동의 화면으로 이동한다

## H. 네트워크와 복구

- [ ] Wi-Fi에서 LTE/5G로 전환해도 새로고침 후 복구된다
- [ ] 오프라인에서 쓰기 시 명확한 오류가 표시된다
- [ ] 앱 강제 종료·재실행 후 세션과 읽지 않은 수가 정상이다
- [ ] Supabase 장애 후 재시도할 수 있고 무한 로딩이 없다
